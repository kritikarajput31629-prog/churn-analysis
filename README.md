Objective

The main goal of this project was to:

Understand customer churn patterns
Identify customers who are more likely to churn
Find the main factors affecting churn
Analyze customer behavior using Power BI
Suggest strategies that could help improve customer retention

Key Insights

Some of the main insights from the dashboard include:

Inactive customers are more likely to churn.
Churn rates differ across different geographic regions.
Customer product usage can be related to churn behavior.
Customer data can be used to identify groups that may need more attention.

Recommendations

Based on the analysis, some possible strategies include:

Creating campaigns to re-engage inactive customers.
Providing personalized offers to customers who are at higher risk of leaving.
Encouraging customers to explore relevant banking products.
Regularly monitoring high-risk customer segments.
